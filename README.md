# Naga Sai — AI Engineering Portfolio

A cinematic, responsive portfolio built with **Next.js 16.3**, **React 19.3**, **TypeScript**, and **Tailwind CSS 4.3**.

## Included
- Resume-driven work experience and education
- 20 AI engineering projects linked to GitHub
- AI systems / architecture section
- Modern frontend stack section
- Voice AI focus section
- Resume download
- GitHub + LinkedIn + email links
- Responsive mobile navigation
- Scroll progress indicator
- Cinematic hero image

## Run locally
```bash
npm install
npm run dev
```
Open `http://localhost:3000`.

## Build
```bash
npm run build
npm run start
```
